# Eyesberg SAAS

SAAS multi-tenant pour configurateur 3D personnalisable.

## 🚀 Démarrage

```bash
# Installer les dépendances
pnpm install

# Lancer en développement
pnpm dev

# Build pour production
pnpm build
pnpm start
```

## 🌐 Domaines

- Production : `eyesberg.app`
- Sous-domaines : `*.eyesberg.app`

## 📋 Variables d'environnement

Voir `.env.local.example` pour la liste complète.
